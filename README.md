-> Project Title : MP3_Tag_Reader

-> Project Description:
- This project is a C-based MP3 Tag Reader developed to extract and display metadata from MP3 files.  
- It reads ID3 tags and shows details such as Title, Artist, Album, Year, Genre, and Comments.  
-The application is implemented using file handling and structures in C.  
-It provides a simple command-line interface to access MP3 file information.  
-This project demonstrates concepts like binary file processing, string handling, and modular programming in C.
 
-> Features:
- Extracts ID3v2 tag information
- Displays Title, Artist, Album, Year, Genre, and Comments
- Menu-driven interface
- Error handling for invalid files
- 
-> Technologies Used
- C Programming
- File Handling
- Structures
- Command Line Interface
